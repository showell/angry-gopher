# Explore apps built by Steve and Claude (2026)

## Safari Screensaver -> /driving
image: /gallery/safari.png
cta: Take a Drive
lang: Zig (WASM) + JavaScript
tech: a Zig core compiled to WebAssembly computes the 3D geometry; a tiny JS blitter just fills the polygons it emits
code: https://github.com/showell/angry-gopher/tree/master/games/driving/wasm
essay: /blog/you-cant-freeze-a-sunset
install: /safari_download/
A first-person motorcycle ride down a winding road — and it steers itself. Hit space and watch it lean through the turns, or step the ride frame by frame. No goal, no clock — just the road.

## Chat -> /chat
image: /gallery/chat.svg
cta: Be social
lang: JavaScript, Zig
tech: live updates over Server-Sent Events; messages persisted to the file system, no database

## Seattle Delivery -> /delivery
image: /gallery/delivery.svg
cta: Ship some Totes
lang: TypeScript
tech: Clarke-Wright savings heuristic + local search over an integer, trig-free cost
code: https://github.com/showell/angry-gopher/tree/master/delivery
essay: /blog/the-ghost-in-the-cost-function
Eight trucks fan out across a deliberately not-to-scale Seattle, delivering a hundred orders a day. The route-planning is a hand-built Clarke-Wright solver — watch it think, or shuffle up a new shift.

## Play Lyn Rummy -> /game
image: /gallery/lynrummy.svg
cta: Match wits with the agent
lang: Zig (WASM) + Elm + TypeScript
tech: a rules DSL sent over the wire — a zig solver picks the plays, an Elm UI referees and renders them
code: https://github.com/showell/angry-gopher/tree/master/games/lynrummy
tutorial: /tutorial
essay: /blog/lyn-never-wrote-it-down
Two-player rummy with a real referee. Build runs and sets against an agent that actually knows the rules, and complete your turn when the board looks right.

## Lyn Rummy Puzzles -> /puzzles
image: /gallery/puzzles.svg
cta: Fix the board
lang: Zig (WASM) + Elm + TypeScript
tech: shares the game's solver and rules; deterministic undo and move-by-move replay
code: https://github.com/showell/angry-gopher/tree/master/games/lynrummy
essay: /blog/two-places-at-once
A single board, mid-game. Drag stacks to merge or split your way to a clean meld layout. Solo, no opponent — undo is free, and Replay walks back your moves.

## Chess Toys -> /chess
image: /gallery/chess.svg
cta: Watch it backtrack
lang: Zig (WASM) + JavaScript
tech: one shared engine — searches emit an event tape of place/remove moves, so every animation scrubs forwards or backwards
essay: /chess/code
code: https://github.com/showell/angry-gopher/tree/master/games/chess
Classic backtracking searches you can watch think: the Knight's Tour (visit all 64 squares exactly once) and Eight Queens (none attacking another). Pieces pile onto the board, hit dead ends, and get pulled back off — red squares mark where attempts died. Pause, scrub backwards, start from any square — and read the zig it all runs on.
